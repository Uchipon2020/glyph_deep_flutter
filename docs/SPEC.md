# 地下迷宮 @（GlyphDeep）ゲーム仕様

Flutter 版の現在の実装に基づく仕様です。HTML 版 v2（`glyph-dungeon-v2.html`）との違いは「14. HTML 版 v2 との違い」にまとめています。

- 数値の定義: `lib/game/data.dart`
- 階の生成: `lib/game/dungeon.dart`
- ルール本体: `lib/game/game.dart`

## 1. 概要

- 記号だけの黒い画面で遊ぶ、ターン制のダンジョン探索ゲーム。スマートフォンの縦画面向け
- 表示名は「地下迷宮 @」、パッケージ名は `info.humedical.glyphdeep`。日本語のみ、広告なし
- 目的: 深さ10で「迷宮の護符」を手に入れ、深さ1の階段を上って地上へ戻る
- 死ぬと最初から。途中保存はなく、端末に残るのはベストスコアと購入フラグだけ
- 通信は課金処理のときだけ

## 2. 進行とターン

プレイヤーが1回行動するたびに、次の順で1ターン進みます。

1. 経過ターン +1、満腹度 -1。満腹度が0以下なら餓死
2. 混乱の残りターン -1
3. HPが最大未満なら、`max(3, 12 - レベル)` ターンごとに1回復
4. 周囲8マスを発見率5%で自動探索
5. 怪物が行動
6. 180ターンごとに60%の確率で、今いる部屋以外に怪物を1体追加

眠っている間はターンが自動で進みます（1回の眠りで最大20ターン）。

ターンを消費しない操作: 鑑定、壁への移動（混乱中を除く）、罠の警告、階段の移動。

## 3. プレイヤー

**初期状態**: HP 16/16、力 16、レベル 1、金貨 0、満腹度 1800/2000

**初期装備**: 棍棒（2-4、装備中）、革鎧（防御3、着用中）、食料1個、投げ矢4本

**レベルアップ**: 累計経験値が 10、20、40、80、160、320、640、1280、2560、5120、10240 に達するごとに上がり、最大HPと現在HPが 4〜8 増える。

**満腹度の段階**

| 満腹度 | 表示 |
|---|---|
| 301以上 | なし |
| 151〜300 | 空腹 |
| 51〜150 | 衰弱 |
| 50以下 | 瀕死! |

段階による能力の低下はありません。

**持ち物**: 最大26欄。投げ矢だけ1欄にまとまり、他は1個で1欄。

## 4. 階の生成

マップは 42×21 マス。3×3 の区画に分け、各区画に部屋または通路の交点を置きます。

- 各区画は82%で部屋になる（最低4部屋）。部屋の床は幅4〜8、高さ3〜4
- 隣り合う区画を全域木でつなぎ、最大3本の余分な通路を足す
- 扉は `6% + 2% × 深さ` の確率で隠し扉になる
- 開始部屋に見える扉がなければ、隠し扉を1つ普通の扉に変える
- 階段は開始部屋以外に必ず1つ置く
- 階を移動するたびに新しく生成する（戻っても同じ階にはならない）

**配置数**

| 対象 | 数 | 場所 |
|---|---|---|
| アイテム | 3〜5個 | 全部屋 |
| 金貨 | 2〜3山（1山 `8〜25 + 深さ × 8` 枚） | 全部屋 |
| 罠 | `1〜2 + 深さ ÷ 3`（切り捨て） | 全部屋 |
| 怪物 | `3〜4 + 深さ ÷ 3`（切り捨て）。40%は眠っている | 開始部屋以外 |
| 護符 | 深さ10に1個（未所持のときのみ） | 全部屋 |

**その他**: 食料は満腹度を2000に戻す。階段の上と、すでに物があるマスには置けない。

## 6. 戦闘

**プレイヤーの攻撃**

- 命中率: `78% + レベル × 1%`（上限95%）
- ダメージ: `武器の威力 + レベル ÷ 2 + 力ボーナス`（最低1）
- 素手の威力: 1-2
- 力ボーナス: 力が17以上のとき `(力 - 16) ÷ 2`（切り上げ）

**怪物の攻撃**

- 命中率: `90% - 防御 × 5%`（30〜95%）

**眠っている怪物**

- 受けるダメージが2倍（不意打ち）
- 自然な眠りは攻撃で覚める。距離3以内に近づくと毎ターン30%で起きる
- 魔法の眠りは、攻撃されても時間が切れるまで覚めない

**投げる**（射程8マス。投げた物は着地点に落ちる）

| 物 | 命中率 | ダメージ |
|---|---|---|
| 投げ矢 | 85% | 1〜4 |
| 武器 | 65% | 武器の威力 + 強化値 |
| 防具 | 55% | 1〜2 |
| 巻物・杖・食料 | 必ず当たる | 効果なし |
| 薬 | 必ず当たる | 表の効果。瓶は割れて消える |

**行動の順序**

1. 再生
2. 眠りの処理
3. 擬態中なら何もしない
4. 隣にいれば攻撃
5. 動かない怪物はここで終わり
6. 遠隔攻撃の判定
7. 移動（プレイヤーへの最短経路）。距離が15以上離れていると、20%の確率でランダムに動くだけ

## 8. 罠

70%は隠れた状態で置かれ、残りの30%は最初から見えています。発動しても消えません。

| 名前 | 効果 |
|---|---|
| 落とし穴 | 1〜3ダメージで次の階へ落ちる。深さ8以降には出ない |
| 眠りガス | 4〜7ターン眠る |
| 矢 | `2〜6 + 深さ ÷ 2` ダメージ |
| 毒針 | 1〜3ダメージ、力 -1（下限3） |
| 警報 | 階の怪物をすべて起こす（魔法の眠りも解ける） |
| 転送 | ランダムな部屋へ移動 |

同じ種類の罠は連続して生成されません。

**踏む前の警告**: 見えている罠へ動くと、警告を出して止まります（ターンは進まない）。もう一度同じマスへ動くと踏みます。混乱中は警告なしで踏みます。

## 9. 探索と視界

- 部屋に入ると部屋全体と壁が記憶される。通路では周囲8マスだけ
- 怪物が映るのは、同じ部屋にいるか隣にいるとき。千里眼中は階全体
- `探` ボタン: 周囲8マスを発見率35%で、最大5ターン調べる。何か見つけるか、ダメージを受けるか、起きた怪物が見えると止まる
- 毎ターンの自動探索の発見率は5%

## 10. 状態異常

| 状態 | 効果 |
|---|---|
| 眠り | 行動できず、ターンが自動で進む |
| 混乱 | 移動の50%がランダムな方向になる。壁にぶつかるとターンを消費。走れない |
| 捕縛 | 捕まえた怪物への攻撃以外では動けない。階の移動、瞬間移動、転送の杖で解ける |
| 千里眼 | 階を移動すると切れる |

## 11. 階段と勝利条件

| 状況 | 階段を使ったとき |
|---|---|
| 護符なし、深さ10未満 | 1階降りる |
| 護符なし、深さ10 | 降りられない |
| 護符あり、深さ2以上 | 1階上る |
| 護符あり、深さ1 | 脱出成功（金貨 +500） |

階段の上にいないときにボタンを押すと、階段が見えていれば自動で移動します。

**スコア**: `金貨 + 終了時の深さ × 50`。端末に最高記録を保存します。

## 12. 無料版と課金

- 深さ1〜3は無料。深さ3の階段で購入画面が開く
- 無料版の深さ3では、落とし穴に落ちても下の階へ行かない
- 「深部解放」（`info.humedical.glyphdeep.fullunlock`、買い切り）で深さ4〜10と護符を解放
- 応援（`tip120`、`tip360`、`tip1000`）はゲーム内容に影響しない
- ヘルプ画面から「購入を復元」できる

## 13. 画面と操作

**画面構成**（上から）: メッセージ3行、マップ、ステータス2行、操作ボタン

**記号**

| 記号 | 意味 | 記号 | 意味 |
|---|---|---|---|
| `@` | 自分 | `*` | 金貨 |
| `.` | 床 | `!` | 薬 |
| `\|` `-` | 壁 | `?` | 巻物 |
| `+` | 扉 | `)` | 武器・投げ矢 |
| `#` | 通路 | `]` | 防具 |
| `%` | 階段 | `:` | 食料 |
| `^` | 見つけた罠 | `/` | 杖 |
| `,` | 護符 | `A-Z` | 怪物 |

**タッチ操作**

| 操作 | 動作 |
|---|---|
| 十字ボタン | 1歩進む。怪物へ動くと攻撃 |
| 十字ボタン長押し（0.33秒） | 何かあるまで走る |
| 中央 `休` | 1ターン休む。長押しで回復まで休む（狙い中は取消） |
| マップをタップ | 隣なら1歩、遠くなら見えている場所まで自動移動 |
| `持物` | 使う、装備、鑑定、投げる、置く |
| `階段` | 階段を使う。護符所持中は `階段(上る)` と表示 |
| `探` | 周囲を調べる |
| `投` | 持ち物を選んで投げる |
| `？` | 遊び方、購入、復元 |
| メッセージ欄をタップ | 履歴（直近60件） |

投げる向きと杖を振る向きは、十字ボタンかマップのタップで選びます。

**走る・自動移動が止まる条件**

- ダメージを受けた、新しいメッセージが出た、混乱している
- 同じ部屋または隣に、起きている怪物がいる。または眠っている怪物を新しく見つけた
- 扉、階段、分かれ道に着いた。新しいアイテムや罠が隣に現れた

千里眼で映っているだけの遠くの怪物では止まりません。姿が見えない怪物と擬態中の怪物も判定に含みません。

**キーボード**: `hjklyubn`・矢印で移動、Shift+移動で走る、`.` 休む、`Z` 回復まで休む、`s` 探す、`t` 投げる、`>` `<` 階段、`i` 持物、`?` ヘルプ、`Esc` 取消

## 14. HTML 版 v2 との違い

**追加したもの**

- 怪物15種: ケストレル、レプラコーン、氷の怪物、ガラガラヘビ、眠り蛾、ハエトリソウ、アクエイター、ニンフ、ケンタウロス、ゼロック、メデューサ、ファントム、グリフォン、ユニコーン、ジャバウォック
- HTML 版と共通の怪物への特技: ゾンビ（遅い）、トロル（再生）、レイス（レベルを奪う）、ヴァンパイア（最大HPを奪う、再生）、ドラゴン（炎）
- 薬: 千里眼、混乱
- 巻物: 識別、眠りの霧、大声
- 状態異常: 混乱、捕縛、千里眼
- 無料版と課金、ベストスコア保存の仕組み

**操作の違い**

- 投げる向きと杖の向きは、別画面ではなく十字ボタンかマップで選ぶ（敵のいる方向の ● 表示はない）
- 罠の警告の直後に長押ししても走り出さない（HTML 版ではそのまま踏んでしまう）
- 金貨が足りないとき、鑑定ボタンは押せない

**HTML 版と同じもの**: 階数（10階）、階の生成、罠、鑑定、基本の戦闘式、満腹度、スコア、共通13種のうち追加特技以外の数値
